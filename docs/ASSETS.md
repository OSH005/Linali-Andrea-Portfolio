# Asset map

Every image the site uses: where the original lives, what the site generates from it, and where it appears.

**Two copies of everything:**
- **Originals** in `media-src/` (git-ignored, large). The client's Google Drive is the master copy. Never edit originals in place.
- **Web versions** in `site/public/media/`, generated by `cd site && npm run media -- <slug>` (or `--all`). Committed. AVIF + WebP at 640 / 1280 / 2400 px (never upscaled; a smaller source keeps its own width), plus a 4800 px WebP zoom for spreads. All metadata (EXIF, GPS) stripped.
- `site/src/generated/media-manifest.json` lists every generated file with its size and a blur placeholder. Components read images **only** through `src/lib/media.ts`.
