# Linali Andrea — portfolio site

The personal portfolio of Linali Andrea, a Sri Lankan womenswear designer (recent graduate). A motion-led story site: her collections in order (mind → body → nature → renewal), ending in one action: get in touch.

## Read first, in this order
1. `docs/START-HERE.md`: where the project stands and what to do next
2. `PRODUCT.md`: who it's for, what must never be invented
3. `DESIGN.md`: the design system ("The Slow Hand"), tokens and rules
4. `PLAN.md`: the full plan (read its top block first: it lists what Phase 1 changed)
5. `docs/ASSETS.md`: every image, where it lives and where it's used
6. The prompt for the phase you're working on: `docs/prompts/`

## Commands (run inside `site/`)
| Command | What it does |
|---|---|
| `npm run dev` | Dev server on http://localhost:3000 |
| `npm test` | Unit tests (jsdom) + media library tests. Must stay green. |
| `npm run test:build` | `next build`, then checks every route exists, CSS modules compiled, every manifest image exists |
| `npm run media -- <slug>` | Rebuild one collection's images (a few minutes) |
| `npm run media -- --all` | Rebuild everything incl. portraits and monogram (~14 min, run in background) |
| `npm run build` | Static export to `site/out/` |

## Rules
- **The brief wins.** Palette, carousel, Tumble Deck, the story order are the client's choices; don't "improve" them away.
- **Never invent facts** (bio, awards, credits, clients, quotes). Drafts are marked `draft: true` and need her approval.
- **Never commit `media-src/`** or anything with EXIF. The media build strips metadata; don't bypass it.
- **Content must be visible without JavaScript and under reduced motion.** No element starts at `opacity: 0` in the HTML. No fade-in-on-scroll everywhere; one authored moment per chapter.
- **Teal `#008794` never on text under 24px** (3.5:1 on cream).
- **Test first** (superpowers:test-driven-development). Behaviour you can only see in a browser gets a check in `scripts/build/` or a Playwright test.
- **Work on a branch per phase**, merge to `main` only when the user says so. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## This Next.js is newer than your training data
Read `site/node_modules/next/dist/docs/` before using an API. Known here:
- Page `params` is a Promise: `const { slug } = await props.params`, typed with the global `PageProps<'/work/[slug]'>`.
- `output: 'export'` cannot use `cacheComponents`/PPR (removed from config).
- `site/AGENTS.md` is regenerated by `next dev`; commit it, don't fight it.

## Gotchas already paid for
- **Turbopack Tailwind rule must target `globals.css` only.** `"*.css"` also caught `*.module.css` and turned every CSS-module class into `undefined` (unit tests can't see it; `npm run test:build` can).
- **Grid children need `min-width: 0`** or a horizontal scroller widens the page on phones.
- **`mix-blend-mode` inside an element with `z-index` blends against nothing.** Put the blend on the stacking-context element itself.
- **Pass stable props to the Tumble Deck** (`useMemo` the `cards`). A new array every render tore down a running page turn and froze cards mid-fall.
- **Dialogs go through `useDialog(open, onClose)`.** It handles native closes (Android back), scroll lock and focus return. Don't hand-roll `<dialog>` logic.
- **sharp on Windows:** `sharp.cache(false)` (open handles block rewrites). `tools/media/` pins one sharp version via `overrides`; two copies crash.
- **The cylinder carousel draws each photo as many slices.** Feed it the 640 px files, never larger.
- **The hidden browser pane runs zero animation frames.** Verify motion with Impeccable's `motion-capture` (headless Chrome), not the pane.
- Design-detector exceptions live in `.impeccable/config.json`, each with a reason. Add new ones the same way, file-scoped.
